# EXP2.37 — Registered decisive validation of the two-term RDA-rho law

**Status:** PREREGISTRATION (frozen before any EXP2.37 cell runs). Authored 2026-07-12.
**Motivation:** the seed-251 result (paper §4.7) is *preliminary out-of-sample consistency* only —
seed 251 was already contaminated as a sibling-control source, there was no frozen tolerance, and
only three new target losses backed five contrasts. This block is the registered decisive test
per the hostile-reviewer prescription in `cx4_blind.txt`.

## 0. Frozen protocol

- **Seed:** ONE untouched seed, shuffle/training = **307 / 307307**. Never used in EXP2.23–2.36.
- **Model/data/config:** identical to §3.1 — Qwen3.5-9B, LoRA r2/alpha4, trl-lib/Capybara
  (5000 train / 64 eval), M=4 learners, 4 fragments, strict full quorum, inner AdamW 1e-3,
  fixed windows, delta-correction off, bf16 wire / f32 syncer math, equal total work (5120 microsteps).
- **Launch discipline:** every cell launched only AFTER an externally timestamped commit of this file
  (S3 object timestamps + git hash). Arm scheduling and hardware allocation randomized.
- **Reporting:** raw eval loss at >=12 significant digits (do NOT rely on the 6-decimal report path).
  Per-example paired bootstrap CI on every registered contrast.
- **Acceptance band (frozen):** a contrast PASSES if the observed gap lands within
  **+/- 0.018 of the two-term point prediction** (= 2x the development-fit RMSE 0.00905).
  Sign-only agreement is reported separately and is NOT scored as a pass.
- **Competing models scored alongside on every cell:** two-term law, aligned-only, superseded
  single-term (`eta/(1-mu*rho)`). Per-cell competing predictions are regenerated from the frozen
  fit in `experiment-results/EXP2/rda-rho-law/summary.json` at registration time.

monotone-in-mu rise at matched eta_eff that lands in-band is the decisive positive evidence for v;
a flat (in-band-of-zero) row falsifies the variance term.

## 3. Decision rule (frozen)

- **Two-term law corroborated** iff >= 4/5 contrast-block gaps AND >= 4/6 matched-triad gaps land
  within their +/- 0.018 bands, with the matched-triad rows monotone in mu.
- **Variance term v identified** iff the matched-triad gaps are in-band and non-zero while
  aligned-only's ~0 prediction is out-of-band low.
- **Cross-H claim** downgraded to directional only unless contrast 3 lands in-band.
- All inferential language dropped for any cell whose paired bootstrap CI spans zero.
