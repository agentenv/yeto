# Spec Delta

## Purpose

保证 Miles RL 岛的本地训练真正改动它的 LoRA 适配器：反向产生的梯度能到达优化器，优化器步能改变参数，并且一轮在真实优势上训练却没产生梯度时会显式失败，而不是把数值噪声当成结果提交给 syncer。

## ADDED Requirements

### Requirement: policy-sync 暴露参数时不得破坏 autograd 状态

把 fp32 优化器 master 权重暴露给 policy-sync 转换层的过程 SHALL NOT 扰动模型可训练参数的 autograd 状态。在任何一次导出或应用全局策略之后，每个可训练参数 SHALL 保持其原有的梯度累加器，使得分布式训练后端注册的梯度累加 hook 在后续反向中继续触发。

#### Scenario: 导出适配器后梯度累加仍然有效
- **WHEN** 岛导出本地适配器以提交给 syncer
- **THEN** 随后的一次反向传播为每个可训练适配器参数填充分布式后端的梯度缓冲区
- **AND** 优化器为这些参数观察到非零梯度

#### Scenario: 应用全局策略后梯度累加仍然有效
- **WHEN** 岛应用从 syncer 收到的全局策略
- **THEN** 下一个本地训练步为每个可训练适配器参数填充分布式后端的梯度缓冲区
- **AND** 该步报告的梯度范数非零

#### Scenario: 参数存储不得跨 dtype 别名
- **WHEN** 集成层需要某个低精度参数的 fp32 master 视图
- **THEN** 它 MUST 在不把不同 dtype 的张量赋给该参数存储的前提下取得该视图

### Requirement: 没有产生梯度的训练轮必须失败

当一轮本地训练报告的梯度范数恰好为零、而该轮的优势不全为零时，岛 SHALL 将该轮视为失败。它 MUST NOT 把结果状态作为正常轮提交给 syncer，且失败信息 SHALL 指明轮次和观察到的梯度范数。

#### Scenario: 优势非零时的零梯度被拒绝
- **WHEN** 某轮的优势中至少有一个非零值
- **AND** 本地训练步报告的梯度范数恰好为零
- **THEN** 该轮以错误失败，错误信息包含轮次和梯度范数
- **AND** 该轮不提交任何本地状态

#### Scenario: 优势完全退化时的零梯度是允许的
- **WHEN** 某轮的全部优势都为零，因而本就不应产生梯度
- **AND** 本地训练步报告的梯度范数为零
- **THEN** 该轮正常进行，不抛出错误

#### Scenario: 正常训练不受影响
- **WHEN** 某轮报告的梯度范数非零
- **THEN** 该轮照常进行并提交本地状态

### Requirement: 岛必须运行包含修复的集成层

RL 岛 SHALL 运行包含本梯度流修复的 Miles 版本。用于开岛的固定版本 SHALL 是决定这一点的机制，使得"只改了集成层源码却没有推进 pin"不会无声地让岛继续跑在损坏的版本上。

#### Scenario: 开出来的岛带有修复
- **WHEN** 开一个 RL 岛，其 setup 按固定版本安装 Miles
- **THEN** 所安装的版本包含该梯度流修复

#### Scenario: 无需 GPU 即可验证梯度流
- **WHEN** 测试套件在没有 GPU 的机器上运行
- **THEN** 有测试断言"把不同 dtype 的张量赋给参数存储会丢掉已注册的梯度累加器 hook"
- **AND** 有测试断言"优势非零时不变量会拒绝零梯度范数"
