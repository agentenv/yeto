## 结论：**尚无净收益边**（合法否定结论）
- 判据（D1-GPU-PLAN §4(3)）：最佳固定配置须在两个 seed 下中位轮时均比其余配置低 ≥10%。
  - T2R2S0 vs T2R1S1：seed17 −1.2%（11.465 vs 11.608），seed29 **+1.6%**（11.881 vs 11.688）——方向随 seed 翻转，差异在噪声内 → **无显著差异**。
  - T1R3S0 比两者慢 ≈55%（18.1 s；trainer 只有 1 卡，训练段翻倍），不是候选。
  - 故没有"最佳固定配置"。
- 每轮 Δ（T2R1S1→T2R2S0，正值=T2R2S0 更快）：median 口径 seed17 +0.143 s、seed29 −0.193 s；mean 口径 +0.452 / −0.007 s；合并 mean +0.223 s（≈1.9%）。
- 回本轮数 =（5.1 up 边 cost_upper 179.7 s + recovery_upper 2.7 s）/ Δ = 182.4 s / Δ：合并 mean Δ → **≈818 轮**；seed17 median → ≈1276 轮；seed29 → 无收益（负值）。反向 T2R2S0→T2R1S1（6.4+1.7 = 8.1 s）仅在 seed29 有 Δ=0.193 s → 42 轮，但同一数据在 seed17 方向相反，不构成稳定收益。
- 因此在该 profile（H100 单节点 4 卡、小模型）下不存在可自动采用的净收益边；6.4 auto 不启用，保持 manual/recommend。动态回放见 `../d2-replay/REPLAY-RESULT.md`"n=3（H100）"节。
- 与 2026-09-30 旧 H100 结果（`../infra-a/2.4/RESULT.md`，T1R3 75 s/轮最佳）不可直接比较：那是另一套参数/运行时（DistOpt 问题之前），本次三配置同 profile 同镜像。
