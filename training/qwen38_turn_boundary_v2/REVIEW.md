# Independent turn-boundary regression review

This version repairs conversion of source assistant events into native assistant turns. The targeted defect is an announcement followed by a separate tool-call event being serialized as two assistant messages, which adds a supervised EOT before the call. A corrected continuation contains the announcement and its call in one native assistant message, with its EOT after the call.

The independent suite in `test_end_to_end.py` exercises raw canonical events, original rollout response items, and ATIF replay through the new source adapters and the pinned native Qwen tokenizer. It does not modify either running trainer, a saved dataset, a frozen evaluation plan, or a checkpoint.

## Required invariants

- Preserve explicit final, role, and known source-turn boundaries. Message IDs and response IDs are not guessed to be turn IDs. Removed reasoning-only events must retain explicit boundary information.
- Preserve the order and IDs of parallel calls and their actual observations. Reject same-turn text appearing after tool calls when the native representation would move that text before the calls. A true explicit later turn can remain separate.
- Remove original inline reasoning before deciding whether a replay assistant message is empty. An empty reasoning-only assistant must never become a supervised EOT-only example.
- Compare complete rendered bytes and tokenizer IDs to the native template. Train only actual assistant text, tool serialization and EOT; mask headers, thinking wrappers, original observations, system/user content, and post-EOT newlines.
- Retain unshifted canonical arrays. The existing pure-Python NeMo adapter performs exactly one next-token label shift. Prefix truncation retains exactly the first 262144 IDs and labels without retokenizing or appending an EOT.
- Preserve generated-CoT receipts, source/prefix hashes and original insertion position. A generation before the first merged visible event remains masked input. A later generation that would move ahead of earlier visible content must exclude the whole source with an explicit reason and excluded-gap count.
- Require a hash-bound normalization audit before labeling a no-CoT rendered result as the new turn-boundary contract. Changed post-normalization messages must fail that audit.

## Evidence and limits

CPU environment: `/private/tmp/yeta-qwen38-mask-py3/bin/python`, Transformers 5.8.1, tokenizers 0.22.2, pytest 9.1.1, using the existing public pinned assets in `training/qwen38_no_cot/assets`. This environment has no PyTorch or NeMo installation. The suite exercises the real tokenizer, exact masks and existing shift function; it does not qualify GPU memory behavior, context-parallel kernels, checkpoint reload, or an installed NeMo collator.

The complete current turn-boundary package passed **140 CPU tests in 31.81 seconds**, including the independent native/mask/262144/shift end-to-end suite and 30 data/recipe/runtime contract tests. These include a real CPU source-job rebuild, qualification, and train/validation loading; two genuinely different >262144-token native traces that become identical after truncation; index/shard corruption; empty EOT-only rejection; immutable resume identity; and negative tests for changed memory, shift, model initialization, optimizer, batch and partial-run settings. The suite initially found a masked-wrapper integration error: source channel/turn metadata was placed in message payloads while the normalizer read a separate boundary array. That dispatch was corrected without weakening the tests. An explicit `end_turn` boundary and standalone reasoning-only replay rejection also pass. This is CPU conversion/loader evidence, not a model recovery result.

When explicit turn metadata is absent, adjacent assistant continuation grouping is a documented inference. It cannot recover the original turn with certainty from message IDs alone. Strict exclusions may reduce corpus coverage and must be counted before any regenerated dataset is admitted. New source/normalizer/renderer identities require a fresh export and validation; the old frozen dataset and checkpoint identities remain unchanged.

These tests can establish conversion correctness on their fixtures, not that training on corrected data restores tool-use behavior. Recovery requires a new, explicitly authorized training/evaluation comparison. The existing corrected evaluation's announcement-then-stop pattern is supporting diagnostic evidence, not proof that this converter defect is its sole cause.

The new no-CoT loader reconstructs the full assistant/body/tool/EOT mask from actual native token boundaries, verifies source/normalizer/render identities and hash-bound row bytes, then invokes the existing single causal shift. Its corpus qualifier checks source and normalized-message uniqueness, complete shard coverage and train/validation session-group separation. The final local builder and qualifier now also deduplicate/reject the joint retained input-ID and label arrays after 262144 truncation. The regression uses two actual long native renderings with different full tails and verifies this rejection. A two-source, one-worker rebuild then qualified and loaded one train and one validation row with complete accounting. Fresh-run tests reject occupied output, alternate model path, model state-dict/loader overrides, optimizer replacement, double shifting and changed CP/memory policies. The immutable runtime delegation restores its original functions even after exceptions, and its resume identity binds loss, clipping and scheduling settings. These are implementation tests; the complete regenerated production corpus, real pinned base assets, exact-image collator, checkpoint freshness and CP8 launch preflight must still pass their actual operational gates before restarting GPUs.

Final source audit found an additional typed-action edge case: the inherited private-channel filter removes an explicit function/custom tool-call event if that event carries `channel=analysis`. Private analysis message text should be removed, but an explicitly typed call remains an action. The new regression reproduced an orphaned observation after the call was dropped. Canonical, rollout and masked replay regressions now preserve these actions while still removing private analysis message text. The immutable original generation contract continues to reject unsupported top-level analysis projections: original receipts are never rewritten to bypass that guard. The prevalence in the real corpus has not been measured by these fixtures.
